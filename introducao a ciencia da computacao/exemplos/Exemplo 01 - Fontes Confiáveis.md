# Semana 1 - Como pesquisar sobre uma subárea da Computação

Ao final desta semana, cada grupo deverá ser capaz de:

1. compreender o tema geral da subárea escolhida;
2. identificar fontes confiáveis de pesquisa;
3. levantar conceitos, aplicações e problemas estudados pela subárea;
4. dividir responsabilidades entre os integrantes do grupo.

A Semana 1 é uma etapa de **planejamento e estruturação**. O foco ainda não é produzir o texto final ou os slides completos, mas construir uma base sólida para o desenvolvimento do trabalho nas semanas seguintes.

---

## 1. Entendendo o objetivo da pesquisa

Cada grupo ficará responsável por estudar uma das seguintes subáreas da Ciência da Computação:

1. Teoria da Computação  
2. Compiladores e Linguagens de Programação  
3. Sistemas Operacionais  
4. Redes de Computadores  
5. Banco de Dados  
6. Engenharia de Software  
7. Segurança da Informação  
8. Interação Humano-Computador  
9. Computação Gráfica  
10. Inteligência Artificial  

O objetivo da pesquisa não é apenas encontrar uma definição da área. O grupo deve construir uma explicação que ajude os colegas a compreenderem:

- o que essa subárea estuda;
- por que ela é importante;
- quais problemas ela ajuda a resolver;
- onde ela aparece na prática;
- como ela se relaciona com outras áreas da Computação;
- quais são seus desafios atuais.

---

## 2. O que significa pesquisar bem?

Pesquisar bem não significa copiar informações da internet. Uma boa pesquisa envolve:

- procurar fontes confiáveis;
- comparar diferentes explicações;
- selecionar as informações mais importantes;
- organizar as ideias com lógica;
- escrever e explicar com as próprias palavras;
- registrar corretamente as fontes utilizadas.

O trabalho não deve ser apenas uma coleção de definições soltas. O grupo precisa construir uma explicação organizada, clara e contextualizada sobre a subárea estudada.

---

## 3. Fontes que podem ser utilizadas

Os grupos devem priorizar fontes confiáveis.

## Fontes recomendadas

- livros de Computação;
- artigos científicos;
- materiais de universidades;
- documentação oficial de tecnologias;
- páginas institucionais;
- materiais didáticos produzidos por professores ou instituições reconhecidas.

## Fontes que exigem cuidado

- blogs sem autoria clara;
- vídeos curtos sem base teórica;
- sites com excesso de propaganda;
- textos sem referências;
- respostas prontas de fóruns;
- materiais que não indicam autor, data ou origem.

Essas fontes podem ser úteis para um primeiro contato com o tema, mas não devem ser a principal base do trabalho.

---

## 4. Como avaliar se uma fonte é confiável?

Antes de usar uma fonte, o grupo deve analisar alguns pontos:

| Pergunta | Por que isso importa? |
|---|---|
| Quem escreveu esse material? | Ajuda a verificar a autoridade da fonte. |
| A fonte é de uma universidade, editora, organização ou documentação oficial? | Fontes institucionais costumam ser mais confiáveis. |
| O texto apresenta referências? | Mostra que o conteúdo tem base em outros materiais. |
| A informação está atualizada? | Algumas áreas mudam rapidamente. |
| O conteúdo é explicativo ou apenas superficial? | Trabalhos acadêmicos precisam de explicações mais completas. |
| A fonte ajuda a entender o tema ou apenas traz frases prontas? | O grupo precisa compreender, não apenas reproduzir. |

---

## 5. Estratégia de pesquisa

Evite iniciar a pesquisa com buscas muito amplas, como:

> “Tudo sobre Inteligência Artificial”

Esse tipo de busca pode gerar muitos resultados genéricos e difíceis de organizar.

Uma estratégia melhor é dividir a pesquisa em perguntas menores.

### Exemplo para Banco de Dados

- O que é Banco de Dados?
- Quais são os principais conceitos de Banco de Dados?
- O que é um Sistema Gerenciador de Banco de Dados?
- Quais problemas a área de Banco de Dados resolve?
- Onde bancos de dados são usados?
- Qual a relação entre Banco de Dados e Engenharia de Software?
- Quais são os desafios atuais da área?

### Exemplo para Sistemas Operacionais

- O que é um Sistema Operacional?
- Quais recursos do computador ele gerencia?
- O que são processos?
- O que é gerenciamento de memória?
- Como o sistema operacional organiza arquivos?
- Qual a relação entre Sistemas Operacionais e Segurança da Informação?
- Quais são exemplos de sistemas operacionais usados atualmente?

---

## 6. O que cada grupo deve pesquisar inicialmente?

Cada grupo deve buscar respostas para os seguintes pontos:

### 1. Definição da subárea

Explique o que essa área estuda.

### 2. Principais conceitos

Identifique os conceitos básicos que alguém precisa conhecer para entender essa área.

### 3. Problemas estudados

Explique que tipos de problemas essa área tenta resolver.

### 4. Aplicações práticas

Mostre onde essa área aparece no mundo real.

### 5. Relação com outras áreas

Explique como essa subárea se conecta com outras partes da Computação.

### 6. Tecnologias, ferramentas ou exemplos

Identifique linguagens, ferramentas, sistemas, plataformas ou aplicações associadas à subárea.

### 7. Desafios atuais

Pesquise dificuldades, tendências ou temas recentes relacionados à área.

## Exemplo parcialmente preenchido

### Subárea: Banco de Dados

| Item | Exemplo |
|---|---|
| Nome da subárea | Banco de Dados |
| Definição inicial da subárea | Área responsável pelo estudo de formas de armazenar, organizar, consultar e gerenciar dados em sistemas computacionais. |
| 5 conceitos principais | Dados, banco de dados, SGBD, tabela, consulta. |
| 3 problemas estudados pela área | Como armazenar grandes volumes de dados; como recuperar informações rapidamente; como garantir segurança e consistência dos dados. |
| 3 aplicações práticas | Sistemas bancários, sistemas acadêmicos, lojas virtuais. |
| 3 tecnologias, ferramentas ou exemplos | MySQL, PostgreSQL, Oracle Database. |
| Relação com outras áreas da Computação | Relaciona-se com Engenharia de Software, Segurança da Informação, Inteligência Artificial e Sistemas Distribuídos. |
| 5 fontes confiáveis encontradas | Livros, documentação oficial, materiais de universidades, artigos ou sites institucionais. |
| Dúvidas iniciais do grupo | Diferença entre banco de dados relacional e não relacional; diferença entre banco de dados e SGBD. |

O trabalho deverá conter, obrigatoriamente, as seguintes partes:

### 1. Descrição do Projeto de Práticas Extensionistas

Apresentar um texto breve contendo:

- Nome e objetivo geral do projeto de extensão;
- Público-alvo e comunidade/instituição atendida;
- Principais atividades e problema que o projeto busca resolver;

### 2. Modelo Entidade-Relacionamento (MER)

Elaborar o diagrama Entidade-Relacionamento do banco de dados que atenderá o projeto de extensão, contendo:

- No mínimo 5 entidades relacionadas entre si;
- Atributos de cada entidade, com destaque para a chave primária (PK);
- Cardinalidade de cada relacionamento (1:1, 1:N ou N:N), indicada no diagrama;

> **Observação:** o diagrama deve ser inserido como imagem no documento final (print, exportação ou foto legível).

### 3. Script DDL de Criação do Banco de Dados

A partir do MER elaborado no item anterior, o aluno deverá escrever os comandos DDL (Data Definition Language) para criação do banco de dados em um SGBD relacional (MySQL, PostgreSQL ou similar), contendo:

- Comando `CREATE DATABASE`;
- Comando `CREATE TABLE` para cada entidade do modelo, com tipos de dados adequados;
- Definição de chaves primárias (`PRIMARY KEY`) e estrangeiras (`FOREIGN KEY`).
- Restrições adicionais pertinentes (`NOT NULL`, `UNIQUE`, `DEFAULT`), quando fizer sentido para o projeto.

### 4. Consultas em Álgebra Relacional

Elaborar 3 (três) consultas utilizando a notação de Álgebra Relacional (operadores como σ - seleção, π - projeção, ⋈ - junção, ρ - renomeação, ∪, ∩, − etc.), sendo que:

- Cada consulta deve envolver, no mínimo, 3 (três) tabelas do modelo criado;
- Cada consulta deve vir acompanhada de uma breve descrição em português do que ela retorna;
- As consultas devem fazer sentido para o contexto do projeto de extensão
- Justificar a importância de cada consulta para o projeto
